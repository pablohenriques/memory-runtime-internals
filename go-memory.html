Go vs JVM — diferenças fundamentais

Go
AOT — compila direto para binário nativo
Stack por goroutine — começa com ~2KB, cresce dinamicamente
Escape Analysis — compilador decide stack vs heap
GC tricolor — mark-and-sweep concorrente, baixa latência
Sem JIT — código nativo desde o início
Goroutines — M:N threading, ~2KB vs ~1MB thread OS
JVM / Kotlin
JIT — bytecode compilado em runtime conforme aquece
Stack por thread OS — fixa, ~512KB–1MB
Sempre na Heap — objetos sempre alocados pelo GC
GC geracional — Eden, Survivor, Old Gen
Metaspace — metadados de classes em memória nativa
Threads OS — mais pesadas, limite do SO
