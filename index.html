Memory & Runtime Internals

Uma coleção de guias visuais e interativos sobre como linguagens de programação gerenciam memória, organizam a execução e funcionam por dentro. Cada documento explora a arquitetura interna de uma linguagem de forma visual e acessível.

// sobre esta coleção

Esta série aborda os mecanismos internos de algumas das linguagens mais usadas no mercado. O foco está em como cada linguagem gerencia a memória (stack, heap, regiões estáticas) e como o runtime organiza a execução de um programa — do código-fonte até os registradores da CPU.

Cada guia é autocontido e visualmente rico: diagramas de layout de memória, animações conceituais, exemplos de código e comparações entre estratégias (GC, ARC, ownership, contagem de referências etc.). O material é voltado para desenvolvedores que já conhecem a linguagem mas querem entender o que acontece por debaixo dos panos.
